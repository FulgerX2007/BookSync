BookSync

End-to-end encrypted bookmark sync

This is a BookSync sync server. It keeps your bookmarks in two-way sync between Chrome, Edge, Brave, Vivaldi, Opera and Firefox, and it only ever sees ciphertext.

Connect your browser

Three steps, once per browser.

  1. Install the BookSync extension From the releases page, for Chromium browsers or Firefox.
  2. Open its settings and enter this server's address {{.ServerURL}}

    If this server is behind a path prefix, include it.

    {{if .NeedsHTTPS}}

    The extension requires HTTPS. Put this server behind a TLS proxy and use its https:// address.

    {{end}}
  3. {{if .Info.RegistrationOpen}}Create an account, or sign in{{else}}Sign in{{end}} {{if .Info.RegistrationOpen}}The first browser creates the account and shows your SyncID once. Every other browser signs in with your username, password and that SyncID.{{else}}Sign-up is closed on this server. Sign in with your username, password and SyncID.{{end}}

What this server can see

Very little, by design.

Only ciphertext

Your bookmarks are compressed and AES-256-GCM encrypted in the browser before upload.

No password, no SyncID

Keys come from your password and SyncID, which never leave your browsers. The server keeps an Argon2id hash of a derived key.

Rollbacks are caught

Every vault carries an encrypted sequence number, so a server restored from an old backup is detected, not trusted.

API reference

JSON over HTTPS. Errors look like {"error":{"code","message"}}; clients branch on code.
